# Wood Pricing API

Backend em Node.js, Express, TypeScript, PostgreSQL e Prisma para gestão de custos e
precificação de produtos artesanais de madeira.

## Instalação

npm install
npx prisma migrate dev
npx prisma generate
npm run dev

## Variáveis de ambiente

Crie um arquivo .env baseado no .env.example com sua string de conexão do PostgreSQL.
